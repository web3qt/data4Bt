#### 问题1: ExpectedRecords计算异常
**现象**: 所有月份的expected_records显示为0
**影响**: 无法正确计算完整性比例
**根因分析**:
- ExpectedRecordsCalculator本身工作正常（独立测试显示2023-01应为44640条记录）
- 问题可能在于GetMonthlyDataStats数据库查询
- 或者在错误处理逻辑中被重置为0

**测试证据**:
```bash
# 独立测试ExpectedRecordsCalculator
Expected records for 2023-01: 44640  # ✅ 正常
Expected records for 2023-02: 40320  # ✅ 正常

# 但在verify-data命令中
"expected_records": 0  # ❌ 异常
```

#### 问题2: 月度完整性状态异常
**现象**: 所有月份状态显示为"unknown"
**影响**: 无法正确识别缺失和不完整的月份
**关联**: 与问题1相关，因为expected_records为0导致状态计算错误
